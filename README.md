# GoOdDd pattern matcher 

# Purpose

A C++ tool designed to read an input file, shuffle text buffers randomly, and execute recursive backtracking searches to find complex structural patterns based on alternating case rules and triangular character frequency constraints.

# Concept 
This program reads a file, repeatedly shuffles its text, and extracts random substrings. It tests these buffers against a complex, expanding character frequency pattern with alternating cases using a backtracking search. It runs for a specified number of iterations and tallies the matches.
